# Chan Chart Reader

Use this skill when the user asks for Chan theory charts, trend structure, divergence, fractals, strokes, segments, or generated chart artifacts.

## Rules

- Use generated chart artifacts or formal tool output as the source of truth.
- Do not create chart paths, signal counts, or divergence labels by imagination.
- Ask for a security code when a name is ambiguous.
- Keep chart interpretation separate from trade recommendation.
- Mention date range, symbol, artifact URL/path, and tool status in the reply.

## Reading Order

1. Confirm symbol, date window, and timeframe.
2. Report chart artifact URL/path.
3. Summarize structure: trend direction, key pivots, divergence, and strength notes.
4. Connect chart structure to broader market context only when supporting data is available.
5. List watch conditions instead of declaring certainty.
